# Kurena-chan's A to T Adapter

A ポーズのまま着せた衣装を、T ポーズのアバター（くれなちゃん）に合わせて T ポーズに補正する Unity エディタ拡張です。

衣装にコンポーネントを付けるだけで、Scene ビューでは T ポーズで表示され、アバターのビルド時にも反映されます。
メッシュのアセットは変更しない、NDMF による非破壊の処理です。

衣装のボーンは動かさず、衣装メッシュの bindpose（メッシュとボーンの対応付け）だけを書き換えます。
そのため、Modular Avatar の Setup Outfit の前後どちらで使っても、Setup Outfit に打ち消されることはありません。

## 想定している使い方

アバターと衣装の組み合わせによっては、Modular Avatar の Setup Outfit を実行したあとも、衣装の腕が A ポーズのような見た目のまま残ることがあります。
このツールは、そのような場合に上腕のメッシュを回転させて、T ポーズのアバターに合わせるためのものです。

## 動作環境

- Unity 2022.3
- [NDMF](https://github.com/bdunderscore/ndmf) 1.13.0 以上（Modular Avatar を使っている場合は、すでに入っています）

## 導入

1. VRChat Creator Companion（VCC）の Settings → Packages → Add Repository で、次の URL を追加します。
   ```
   https://fluffite.github.io/vpm/index.json
   ```
2. プロジェクトの Manage Project で「Kurena-chan's A to T Adapter」を追加します。

VCC を使わない場合は、[Releases](https://github.com/fluffite/kurena-a2t/releases) から `.unitypackage` をダウンロードしてインポートすることもできます。

## 使い方

1. 次のどれかの方法で、衣装のゲームオブジェクトに「Kurena-chan's A to T Adapter」コンポーネントを付けます。
   - ヒエラルキーで衣装のゲームオブジェクトを右クリックし、`FluffLabs > Kurena-chan's A to T Adapter` を選ぶ
   - 衣装のゲームオブジェクトを選んで、メニューバーの `Tools > FluffLabs > Kurena-chan's A to T Adapter` を選ぶ
   - インスペクターの Add Component から `FluffLabs > Kurena-chan's A to T Adapter` を選ぶ
2. 付けた時点で、Scene ビューの表示が T ポーズになります。通常は、これだけで完了です。
   - 衣装の Left arm / Right arm は自動検出されます。通常、変更する必要はありません。
   - 「処理対象のメッシュ」を開くと、変換するメッシュを選べます（腕のボーンにウェイトがあるメッシュが初期状態で選ばれています）。
3. 必要に応じて「回転量」を選びます。
   - **ビルトイン（くれなちゃん）**：くれなちゃん向けの計測値を使います。通常はこれを選びます。
   - **アーマチュアの差分**：回転前・回転後の 2 つのアーマチュアから、腕の回転の差分を求めます。
   - **直接入力**：親ボーン（肩）の空間でのオイラー角を入力します。

「Scene ビューでプレビューする」のチェックを外すと、Scene ビューでは元の見た目に戻ります（ビルド時の反映には影響しません）。

### オプション：メッシュをアセットとして出力して適用

NDMF を使わずに、変換したメッシュをファイルとして使いたい場合の方法です。
インスペクターの「オプション：メッシュをアセットとして出力して適用」を開き、[保存して適用...]（メッシュが複数の場合は [各メッシュを保存して適用...]）を押して保存先を選びます。
変換したメッシュを `.asset` ファイルとして保存して衣装に割り当て、コンポーネントを取り除きます。Undo（Ctrl+Z）で元に戻せます。

- **反映前の衣装オブジェクトのバックアップを残す**：反映前の衣装を複製し、名前に `_Backup` を付けて非アクティブにして残します。Prefab から配置した衣装は、Prefab とのつながりを保ったまま複製します（ヒエラルキーの Duplicate と同じ方法を使うため、Unity 2022.3 以外では警告を表示します）。
- **複数のメッシュを１ファイルにまとめる**：オンにすると、すべてのメッシュを 1 つの `.asset` ファイルに保存します。オフのときは、選んだフォルダにメッシュごとの `<メッシュ名>_A2T.asset` を保存します。

## 注意事項

- 元のメッシュは変更しません。
- 0.1.x でメッシュを差し替えた衣装にこのコンポーネントを付けると、回転が二重にかかります。元のメッシュに戻してから付けてください。
- オプションで保存したファイルは、Undo しても削除されません。
- オプションでメッシュごとに保存するとき、同じ名前のファイルがあれば確認なしで上書きします（GUID は保たれるため、以前の割り当ては外れません）。
